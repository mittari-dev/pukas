# Busca (robô de notícias com curadoria): plano de implementação

> **Para quem executa:** superpowers:executing-plans (nativo, escolhido pelo fundador), tarefa por tarefa.

**Objetivo:** a seção BUSCA do painel. Três vezes por semana, ou no "Rodar agora", o robô monta uma pauta curta e bem justificada. A equipe escolhe as candidatas, e o robô escreve o rascunho delas como Notícia em revisão. Tudo isso dentro do teto de R$ 50 por mês.

**Arquitetura:**
- Quatro tabelas com RLS.
- Regras puras em `src/lib/busca/` (custo, teto, hora de rodar, pedido à API, esquema da saída).
- Um script `scripts/busca.ts`, que roda no GitHub Actions a cada 15 minutos com a chave mestra.
- A página `/painel/busca`, com o cliente da sessão.
- A chamada à API usa streaming com `finalMessage()`, as ferramentas `web_search_20260209` e `web_fetch_20260209`, e `output_config.format` com `zodOutputFormat`. Quando a resposta para com `pause_turn`, o laço reenvia a conversa.

**Stack:** Astro 7 SSR, Supabase, `@anthropic-ai/sdk` (instalado), zod, Vitest, GitHub Actions.

**Spec:** `docs/specs/2026-11-07-busca-design.md` (aprovada; as quatro decisões do §8 foram aprovadas: busca livre ligada, editor e revisor escolhem, rodadas às 7h, assinatura "PUKAS" com a marca "robô" só no painel).

## Regras globais

- O modelo é `claude-sonnet-5-5`, com `output_config.effort: 'medium'` e sem `thinking`. Preço: US$ 2 por milhão de tokens de entrada, US$ 10 por milhão de saída e US$ 10 por mil buscas.
- A ferramenta de busca é `{ type: 'web_search_20260209', name: 'web_search', max_uses, allowed_domains? }` e a de leitura é `{ type: 'web_fetch_20260209', name: 'web_fetch', max_uses, allowed_domains? }`. Quando a busca livre está desligada, as duas recebem `allowed_domains` com os domínios das fontes ativas.
- O robô nunca publica. O rascunho entra como `estado: 'em_revisao'`, `tipo: 'noticia'`, `autoria: 'PUKAS'` e `criado_por: null` (e é isso que marca "robô" no painel), com as fontes preenchidas como `secundaria` e a `checagem` em branco.
- Script só em `public/*.js` (CSP). Fuso `America/Sao_Paulo`. Mensagens ao usuário em português, sem erro cru.
- O CI nunca chama a API de verdade. A rodada real só acontece com o ok do fundador.

## Pontos de atenção na revisão

1. **Teto no limite:** com R$ 49,50 já gastos e o custo médio de R$ 1,20 por rodada, a rodada não acontece e o estado vira `teto` (teste em `podeRodar`).
2. **Duas execuções do workflow ao mesmo tempo:** a mesma rodada não pode ser pega duas vezes. A troca de `na_fila` para `rodando` é um `update … where estado = 'na_fila'` que confere quantas linhas mudou.
3. **Candidata sem fonte ou com link que não é http(s):** é descartada na validação, e as outras da pauta entram (teste no esquema).
4. **Rodada que quebra no meio** (erro da API, JSON inválido): o estado vira `erro`, com o motivo. Nenhuma candidata pela metade é gravada, e o custo do que já foi gasto conta no teto.
5. **Horário:** às 06:59 de segunda ainda não é hora; às 07:05 é; às 07:20, se já rodou hoje, não roda de novo (teste em `horaDeRodar`).

### Tarefa 4: O robô (`scripts/busca.ts` e o workflow)

**Arquivos:**
- Criar: `src/lib/busca/robo.ts`
- Criar: `src/lib/busca/robo.test.ts`
- Criar: `scripts/busca.ts`
- Criar: `.github/workflows/busca.yml`

**Interfaces:**
- **Produz:** `async conversar(api: { stream(p): { finalMessage(): Promise<Message> } }, pedido): Promise<{ mensagem: Message; uso: { entrada; saida; buscas } }>`. Repete enquanto o `stop_reason` for `pause_turn`, devolvendo o conteúdo do assistente na conversa, até 5 voltas, e soma o uso: `usage.input_tokens`, `output_tokens` e `server_tool_use.web_search_requests`.
- **O script**, em cada execução:
  1. lê a configuração;
  2. se `horaDeRodar` disser que sim, cria uma rodada `na_fila` com `pedida_por: null`;
  3. pega uma rodada `na_fila` (troca atômica para `rodando`);
  4. confere o teto com `podeRodar` e, se não der, troca para `teto`;
  5. roda a pauta e grava as candidatas mais o uso, trocando para `pronta`;
  6. para cada candidata `pedida`, roda o rascunho, insere a peça e grava `rascunho` com o `peca_id`;
  7. qualquer erro deixa `erro` com a mensagem, e o custo gasto até ali conta.
- **O workflow:** `cron: '*/15 * * * *'` mais `workflow_dispatch`. Não faz nada sem os segredos `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY` e `ANTHROPIC_API_KEY`. `timeout-minutes: 20`, com `concurrency: busca` para não rodar duas vezes ao mesmo tempo.

- [ ] **Passo 1: Testes que falham** para `conversar`, com uma API falsa: um `pause_turn` seguido de um `end_turn` faz 2 chamadas e soma o uso das duas; com 6 `pause_turn` seguidos, lança "pausou demais".
- [ ] **Passo 2:** implementar `conversar`, o script e o workflow. O script segue o padrão do `scripts/recolher-traducoes.ts`.
- [ ] **Passo 3:** `npm test` e `npm run check`. Commit `feat(busca): robô no GitHub Actions`.
