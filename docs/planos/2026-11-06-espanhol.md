# PUKAS em espanhol — Plano de Implementação

> **Para agentes:** superpowers:executing-plans (método **nativo**). Os passos usam checkbox (`- [ ]`).

**Objetivo:** site inteiro em pt e es (`/es/...`), idioma escolhido no servidor do Vercel e tradução automática de cada peça, com guarda de números.

**Arquitetura:**
- O conteúdo de cada página sai de `src/pages/` e vai para `src/views/`, componentes que recebem `idioma`.
- `src/pages/**` (pt) e `src/pages/es/**` (es) são rotas finas que chamam as views.
- Os textos fixos ficam em `src/i18n/textos.ts`.
- As traduções ficam em coleções `*Es` com só o texto, e são mescladas ao original por uma função pura.
- O middleware na raiz (`middleware.ts`) decide o idioma.
- `scripts/traduzir.ts` gera as traduções pela API do Claude.

**Spec:** [`docs/specs/2026-11-06-espanhol-design.md`](../specs/2026-11-06-espanhol-design.md)

## Restrições globais

- `type Idioma = 'pt' | 'es'`. O padrão é `pt`, sem prefixo. `es` usa o prefixo `/es` e o mesmo caminho.
- `lang`: `pt-BR` e `es-419`. Os `hreflang` são `pt-BR`, `es-419` e `x-default` (que aponta para o pt).
- Espanhol neutro latino-americano ("ustedes", sem "vosotros").
- Tradução guarda só texto. Número, data, fonte, foto e checagem vêm sempre do original.
- Sem JavaScript no cliente. O seletor é um link com `?idioma=`.

## Foco de revisão

1. **Tradução que muda um número** (1925 → 1926): o build falha e lista os números divergentes. → Tarefa 1, `validarNumerosTraducao`.
2. **Página de conteúdo sem tradução:** o seletor ES leva ao índice da seção em espanhol, nunca a um 404. → Tarefa 3, `caminhoAlternativo`.
3. **Loop de redirecionamento:** quem tem cookie `pt` e abre um link `/es/...` não pode ficar preso entre os dois idiomas. → Tarefa 4, testes de `decidirRedirecionamento`.
4. **`Accept-Language` com pesos e variantes** (`es-CL,es;q=0.9,pt;q=0.8`; `pt-PT`): a primeira língua suportada ganha. → Tarefa 4.
5. **Marcações `|` e `*` perdidas pela tradução:** o teste de números não pega isso, então o prompt manda preservar, e o script reclama se a quantidade de `|` mudar. → Tarefa 5.

### Tarefa 1: Núcleo de idioma (puro)

**Arquivos:** `src/i18n/textos.ts`, `src/lib/idioma.ts`, `src/lib/traducao.ts`, `src/lib/formato.ts` (modificar) · testes ao lado.

**Produz:**
- `Idioma`, `IDIOMAS`, `LANG: Record<Idioma, string>`.
- `t(idioma, chave)`, com chaves tipadas a partir de `textos.pt`.
- `formatarData(d, idioma = 'pt')`, com os meses em espanhol `ENE FEB MAR ABR MAY JUN JUL AGO SEP OCT NOV DIC`.
- `prefixar(caminho, idioma)`: `('/cultura','es') → '/es/cultura'` e `('/','es') → '/es/'`.
- `semPrefixo(pathname) → { idioma, caminho }`.
- `caminhoEdicao(serie, n, idioma = 'pt')`.
- `numerosDoTexto(s): string[]`, ordenados, com cada sequência de dígitos (ignora o separador de milhar, `1.000` = `1000`).
- `validarNumerosTraducao(original, traducao): string[]`, que devolve vazio quando bate. Quando não bate: `['faltam: 1925', 'sobram: 1926']`.
- `mesclarEdicao(original, trad)` e `mesclarObra(original, trad)`: trocam `titulo`, `resumo`, `legenda` e `aviso` e marcam `traducao: { revisado, modelo }`.

- [ ] Testes: mesmas chaves em pt e es; meses es; prefixos; `numerosDoTexto('Em 1925, 15 dias e 1.000 operários') = ['1000','15','1925']`; divergência listada; mescla preserva `numero`, `fontes` e `checagem` do original.
- [ ] RED, depois GREEN. Commit `feat(i18n): núcleo de idioma, textos e guarda de números da tradução`.

### Tarefa 4: Middleware de idioma

**Arquivos:** `middleware.ts` (raiz), `src/lib/escolhaIdioma.ts` e teste.

**Produz:**
- `escolherIdioma({ cookie?, acceptLanguage?, pais? }): Idioma`.
- `decidirRedirecionamento(url, cabecalhos): { destino?: string; gravarCookie?: Idioma }`, que só age nas entradas da spec §4 e no parâmetro `?idioma=`.

- [ ] Testes:
  - o cookie ganha de tudo;
  - `es-CL,es;q=0.9,pt;q=0.8` → es;
  - `pt-PT` → pt;
  - `en-US` + país CL → es;
  - `en-US` + país US → pt;
  - cookie pt em `/es/cultura/x` não redireciona (é conteúdo);
  - cookie pt em `/es/links` → `/links`;
  - `?idioma=es` grava o cookie e limpa a URL.
- [ ] Commit.

### Tarefa 5: Tradução automática

**Arquivos:** `scripts/traduzir.ts`, `.github/workflows/traduzir.yml`, `package.json` (script `traduzir`).

- [ ] O script lê as peças publicáveis sem arquivo em `src/content/es/...` e chama a API do Claude com o prompt da spec §5. Ele grava o arquivo com `revisado: false` e `modelo`, e valida os números e a contagem de `|` antes de gravar. Sem `ANTHROPIC_API_KEY`, sai com aviso, código 0.
- [ ] O workflow roda em `pull_request` com mudanças em `src/content/**` e segredo presente. Executa `npm run traduzir` e faz commit e push no branch do PR.
- [ ] Commit.
