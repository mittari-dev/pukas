# Documentação do PUKAS

| Pasta | O que tem |
|---|---|
| [`produto/`](produto/) | Manifesto, posicionamento e modelo editorial |
| [`design/`](design/) | Paleta oficial e canvas de exploração das paletas |
| [`decisoes/`](decisoes/) | ADRs: decisões de arquitetura, com contexto e alternativas |
| [`specs/`](specs/) | Especificações de cada subprojeto, antes do plano e do código |
| [`roadmap.md`](roadmap.md) | Ordem dos subprojetos e status |

## Convenções

- **ADR:** `ADR-NNNN-titulo-curto.md`, numeração sequencial. Uma decisão não é apagada. Quando muda, ganha um ADR novo que substitui o anterior.
- **Spec:** `AAAA-MM-DD-tema-design.md`.
- A fonte editável do manifesto e do manual de identidade é o vault pessoal do fundador. Este repositório guarda uma cópia, que é a referência de engenharia.
